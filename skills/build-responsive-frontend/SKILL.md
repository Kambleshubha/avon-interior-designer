# Responsive Frontend Builder

1. Inspect the repository, preserve existing conventions, and identify the smallest appropriate stack.
2. Build mobile-first semantic HTML and a token-based CSS foundation.
3. Use Grid for page composition, Flexbox for local alignment, and container-based widths.
4. Implement native controls first; add minimal JavaScript only for stateful interaction.
5. Support keyboard navigation, visible focus, Escape behavior, focus restoration, labels, errors, and reduced motion.
6. Optimize images, fonts, script loading, layout stability, and critical rendering.
7. Add animations only after layout and behavior are correct. Prefer transform and opacity with Intersection Observer.
8. Verify responsive widths, keyboard flows, browser behavior, console errors, accessibility, and performance.

Read `references/frontend-checklist.md` before final verification.
