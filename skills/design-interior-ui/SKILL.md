# Interior UI Design

1. Inspect references for reusable principles: hierarchy, rhythm, palette, type roles, image treatment, conversion path, and responsive behavior. Do not reproduce a reference pixel-for-pixel.
2. Establish the audience, primary action, content inventory, and page list before styling.
3. Define tokens for color, typography, spacing, layout width, radius, shadow, and motion.
4. Produce mobile, tablet, and desktop behavior for every major section.
5. Specify default, hover, focus, active, disabled, error, loading, and empty states where relevant.
6. Design with real content constraints, accessible contrast, keyboard operation, and reduced motion.
7. Keep motion restrained and purposeful. Prefer opacity and transform; prohibit scroll hijacking.
8. Finish with an acceptance checklist covering responsiveness, accessibility, content, and performance.

For this project's visual and structural baseline, read `references/interior-web-rules.md`.
