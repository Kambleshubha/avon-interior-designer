# Interior Website Rules

- Favor editorial composition, strong whitespace, warm photography, and short confident copy.
- Combine deep forest or charcoal surfaces with warm ivory and a restrained brass/sand accent.
- Use a display serif sparingly and a legible sans-serif for interface copy.
- Prioritize hero promise, project proof, services, process, testimonials, and consultation CTA.
- Convert complex desktop overlaps into clear single-column mobile reading order.
- Treat photography as content: preserve aspect ratios, art-direct crops, and provide descriptive alt text.
- Use section reveals, subtle image scale, hover lift, and sticky-header transitions only when reduced-motion support exists.
